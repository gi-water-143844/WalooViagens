### Descrição
<p align="justify"> A WaLoo Viagens é uma plataforma de pesquisa e compra de passagens aéreas que permite aos usuários consultar destinos, comparar voos, selecionar datas, escolher assentos, informar dados dos passageiros e realizar pagamentos. Seu objetivo é oferecer uma experiência de compra simples, intuitiva e eficiente, reunindo todas as etapas da viagem em um único ambiente.</p>

### Orientação de Uso
| Tarefa | O que deve ser feito |
|:---|:---|
| **Pesquisar viagem** | Pesquise e encontre uma viagem de acordo com o destino desejado. |
| **Filtrar preferências** | Utilize os filtros disponíveis para refinar os resultados conforme suas preferências. |
| **Comprar passagem** | Selecione a opção de viagem desejada e inicie o processo de compra. |
| **Selecionar assento(s)** | Escolha um ou mais assentos disponíveis para os passageiros. |
| **Informações do passageiro** | Preencha os dados pessoais de todos os passageiros. |
| **Finalizar compra** | Selecione a forma de pagamento desejada e finalize a compra. |
| **Download da passagem** | Baixe o arquivo da passagem adquirida. |
| **Visualizar nota fiscal** | Acesse e visualize a nota fiscal referente à compra. |
| **Ver perfil** | Acesse e visualize seu perfil. |
